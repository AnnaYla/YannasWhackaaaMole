# Whack-A-Mole 🐿️ 

A simple browser game built with HTML, CSS, and JavaScript. Click the moles before they disappear to earn points!

## Features
- Random mole spawning
- Countdown timer
- Score + missed hits tracking
- Supports mouse and keyboard

## How to play
1. Open `index.html` in your browser.
2. Click the moles as fast as you can.
3. Game ends when the timer reaches zero.
